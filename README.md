# AI Chatbot

AI Chatbot is a web-based chatbot application developed using HTML, CSS, and JavaScript. It provides an interactive and user-friendly interface where users can send messages and receive automated responses in real time. The project focuses on creating a simple yet engaging chat experience while demonstrating the practical use of JavaScript for handling user interactions, managing messages, and dynamically updating web page content.

## Features

- Interactive chat interface
- Real-time display of user and chatbot messages
- Automated responses based on predefined logic
- Dynamic message rendering using JavaScript
- Automatic scrolling to the latest message
- Clean and user-friendly layout

## Technologies Used

- **HTML5** – Structures the chatbot interface.
- **CSS3** – Styles the chat layout and visual elements.
- **JavaScript** – Handles user input, message rendering, and chatbot responses.

## Getting Started

To run this project on your local machine:

1. Clone the repository:

   ```bash
   git clone https://github.com/Rashikumari18/AI-CHATBOT.git
   ```

2. Open the downloaded project folder.
3. Open `index.html` in your web browser.
4. Start interacting with the chatbot.
